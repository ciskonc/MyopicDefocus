# 近视离焦护眼工具 · 用户使用说明

> 适用版本：Windows 10 1809 及以上（含 Windows 11）
> 适用系统：x64 桌面

---

## 一、这是什么

这是一款**常驻后台的屏幕护眼滤镜**。它用一层「盖在所有窗口上面」的透明图层，把你屏幕上的画面做一点点处理，让眼睛感觉「屏幕变远了」，从而少一点盯着近距离屏幕带来的疲劳。

### 它到底做了什么

正常情况下，你看到的画面是红、绿、蓝三种颜色叠在一起的。这个工具做的事情是：

1. 把画面**拆成红、绿、蓝三层**；
2. **红色那层原样透传**，一点都不动；
3. **绿色层和蓝色层各自做一次模糊**，而且蓝色层糊得比绿色层更厉害；
4. 最后把三层按你设定的「效果强度」重新叠回原画面。

叠回来的结果：你会在文字边缘、图片轮廓上看到一圈**很淡的彩色镶边**（外侧偏蓝、内侧偏红），但整张画面依然是清晰的、能正常看字的。

### 为什么这样能让人放松

人眼本身的「焦距」在你的视网膜前面。如果画面被模拟成「稍微更远一点」的东西，眼睛的睫状肌就不需要一直用力收缩去对焦近处的东西，疲劳会小一些。

这里说的「更远」不是靠把字变小了实现的，而是靠一种物理现象：不同颜色的光被眼睛聚焦到的位置不一样（叫**纵向色差**），近视的人看远处的时候这种差异会变大。眼睛本身的「近视离焦」大约是 +0.23 度，它恰好能把红色的那份色差抵掉——所以红色那一层原样透传，绿色和蓝色才需要各自模糊。这个工具正是利用了这一点。

### 覆盖哪些程序

它是**全屏叠加层**，所以：

- Word、Excel、VS Code、Visual Studio、浏览器、播放器——**全都有效**；
- 游戏——**有效**（前提是游戏不是「独占全屏」模式，见第八节）；
- 远程桌面、虚拟机——同样有效。

鼠标可以**穿透**这层滤镜：你能正常点击下面的任何东西，滤镜不会挡操作。

### 运行开销

程序安静地待在托盘里，不打扰你：

| CPU 占用 | 约 5%（60 fps 时） |
| 线程数 | 36 |

## 二、快速开始

1. **双击 `MyopicDefocus.exe`**。
   - **第一次运行**会弹出设置向导，让你填三项：屏幕对角线、观看距离、瞳孔直径。照着第三节填就行。

2. **确认托盘图标出现了**。在任务栏右下角（可能需要点一下 `^` 展开隐藏图标区）能看到一个图标。
3. **想调参数**：右键托盘图标 → 打开设置面板。

## 三、第一次运行的向导：三项怎么填

向导只问三个问题。这三项**直接决定**滤镜的强度，填准了才有效。

### 3.1 屏幕对角线（单位：英寸）——量的是物理尺寸

**这一项量的是屏幕「实物」有多大，不是分辨率。**

分辨率是「有多少个像素点」，对角线是「这块屏从左上角到右下角有多少厘米长」。两者完全是两回事——一台 24 英寸的屏可以是 1920×1080，也可以是 2560×1440。

**怎么量：**

1. 拿一把卷尺或直尺；
2. 量屏幕**显示区域**左上角到右下角的**直线距离**（不要量含边框的外壳）；
3. 得到的厘米数 ÷ 2.54 = 英寸数。

**举例：** 你量到 61 cm，那么 61 ÷ 2.54 ≈ 24 英寸，就填 24。

**常见屏幕对角线参考：**

| 设备类型 | 常见对角线（英寸） |
|---------|------------------|
| 13 英寸笔记本 | 13.3 |
| 14 英寸笔记本 | 14.0 / 14.2 |
| 15 英寸笔记本 | 15.6 |
| 16 英寸笔记本 | 16.0 |
| 21.5 英寸台式显示器 | 21.5 |
| 23.8 英寸台式显示器 | 23.8（俗称 24 寸） |
| 27 英寸台式显示器 | 27.0 |
| 32 英寸台式显示器 | 32.0 |

**填错会怎样：** 填小了会让效果**明显偏强**（因为同样的模糊量被算到了更密的像素上），填大了会让效果**偏弱**。这是最值得认真量的一个参数。

### 3.2 观看距离（单位：厘米）——量眼睛到屏幕的实际距离

**这一项量的是你的眼睛到屏幕有多远。**

**怎么量：**

- 最准的方式：拿卷尺，从**眼睛 cornea（黑眼珠中心）**量到**屏幕正对你的那个点**（比如你正在看的那段文字）；
- 嫌麻烦的话：用眼睛到屏幕边缘的距离大致估一下也行，误差 5~10 cm 影响不大。

**常见取值：**

| 使用场景 | 建议填写 |
|---------|---------|
| 笔记本内置屏，贴脸用 | 35 ~ 45 cm |
| 桌面显示器，坐姿正常使用 | 50 ~ 70 cm |
| 大屏 + 沙发距离 | 80 ~ 120 cm |

**填错会怎样：** 距离填得太大 → 效果太弱甚至看不出来；距离填得太小 → 效果偏强，眼睛可能觉得画面「发糊」。默认 40 cm。

### 3.3 瞳孔直径（单位：微米 μm）——基本不用管

瞳孔直径是眼睛里那个「进光孔」的直径。环境越暗，瞳孔越大。

- 默认 **6500 μm**（也就是 6.5 mm），对应一般明亮房间里的瞳孔大小；
- 如果你在**很暗的房间里**用电脑，瞳孔会放大到 7~8 mm，可以改成 7500~8000；
- 如果在**很亮的**环境下，瞳孔会缩到 4~5 mm，可以改成 4000~5000。

**绝大多数人保持默认值 6500 就行。** 这一项不确定时不要动。

## 五、设置面板

### 5.1 怎么打开

右键托盘图标 → **打开设置面板**。

面板是经典 Windows 控件风格（滑块、按钮、复选框），跟着你的系统主题走，不是自定义皮肤。

### 5.2 分成两块：一套通用参数 / 单独改这块屏

面板上半部分让你在两种模式之间二选一：

| 模式 | 含义 | 适用场景 |
|------|------|---------|
| **一套通用参数** | 所有显示器都用同一组参数（效果强度、观看距离、瞳孔直径、屏幕对角线） | 你只有一块屏，或者多块屏规格/用法完全一样 |
| **单独改这块屏** | 只调当前选中的那一块显示器，其他屏不受影响 | 你有笔记本 + 外接大屏，或者两块屏尺寸不同、坐的位置不一样 |

切换到「单独改这块屏」后，面板里会出现一个显示器选择框，选哪块就改哪块。

### 5.3 四个参数分别是什么

| 参数 | 范围 | 默认值 | 作用 |
|------|------|-------|------|
| **效果强度** | 0 ~ 1 | **0.25** | 最终画面里「模糊版」占多大比例。0 = 完全不处理，1 = 完全用模糊版 |
| **观看距离** | 厘米 | **40** | 你的眼睛到屏幕的实际距离。距离越大，模拟的离焦越强、越模糊 |
| **瞳孔直径** | 微米 μm | **6500** | 瞳孔进光孔大小。瞳孔越大，进光越多，弥散越大、越模糊 |
| **屏幕对角线** | 英寸 | **24** | 屏幕的**物理**对角线长度 |

### 5.4 调参建议

**从上往下按这个顺序调，一次只动一个：**

1. **先量准「屏幕对角线」和「观看距离」**。
   这两项是物理量，量错了后面怎么调都别扭。90% 的「没效果」都是这两个填错了。

2. **再调「效果强度」**。
   - 觉得**没感觉** → 从 0.25 往上调，0.35、0.5 逐步试；
   - 觉得**太糊/太怪** → 往下调，0.15、0.1；
   - 上限 1.0 是「完全模糊版」，几乎没法正常看字，**不建议长期用**；
   - 建议的日常区间是 **0.15 ~ 0.4**。

3. **瞳孔直径基本不动**，除非你明确知道自己处在很暗/很亮的环境里。

**「没感觉」和「太糊」是两个方向的问题，区别在这里：**

| 你的感受 | 更可能的原因 | 该动哪个 |
|---------|------------|---------|
| 完全看不出变化 | 效果强度太低，或观看距离/屏幕尺寸填错导致算出来根本没有模糊量 | 效果强度 ↑；先检查距离和尺寸 |
| 边缘彩边太夸张、字发糊 | 效果强度太高，或观看距离填得太小 | 效果强度 ↓；距离调大到真实值 |

### 5.5 两个复选框

| 复选框 | 默认 | 作用 |
|-------|------|------|
| **对截图和录屏隐藏** | 打开 | 让这层滤镜**不出现在截图和录屏画面里**。你录屏给别人看时，对方看到的是**没有滤镜的原始画面**，你自己屏幕上还是有效果的 |
| **开机自启** | 关闭 | 开机后自动运行本程序。开启后会写入当前用户的注册表启动项 |

> **关于「对截图和录屏隐藏」**：这是防止「录屏分享时暴露滤镜」的防录屏特性。**如果你就是想录下带滤镜效果的视频**，把它关掉即可。

## 七、配置文件在哪

程序把设置存在：

```
%APPDATA%\MyopicDefocus\config.json
```

也就是 `C:\Users\<你的用户名>\AppData\Roaming\MyopicDefocus\config.json`。

**如果你之前用过旧版本**（配置写在 exe 同目录的那种），程序第一次运行时找不到上面的新配置，会**自动回退去读 exe 同目录的旧 `config.json`**（字段名是兼容的），读完仍然以新路径保存。

旧配置里的两个字段会被**忽略**：

- `resX` / `resY`（分辨率）—— 现在分辨率**自动探测**，不用手填；
- `targetFps`（目标帧率）—— 现在**每块屏各自跟随自己的刷新率**，也不用手填。

## 八、常见疑问

### Q1：会不会伤眼？

**不会。** 这个工具不改你眼睛的任何生理结构，也没有任何外部输入。它做的事情是「改变屏幕发出的光的颜色分布」，让你眼睛的调焦负担变小一点。

但它**不是医疗器械，也不能替代任何医疗手段**。如果你已经确诊近视、度数在涨，请去看眼科医生。

### Q2：要不要一直开着？

**建议在长时间盯屏幕的工作/学习时段开着。** 典型用法是「上班/写作业时开，休息、看远处、下班就关」。

不需要时刻盯着屏幕时（比如只是回几条消息），关掉也完全没问题——滤镜本身不会「积累」什么。

### Q3：为什么我截图看不到效果？

**因为「对截图和录屏隐藏」这个开关默认是打开的。**

这是**故意的设计**：滤镜层对截图工具隐藏，所以别人看你的截图/录屏时看到的是**原始画面**，不会看到奇怪的彩边。

**如果你想录下带滤镜效果的画面**：打开设置面板 → 取消勾选「对截图和录屏隐藏」→ 保存。关闭后截图里就会带上滤镜效果了。

### Q4：为什么画面边缘有彩边？这是 bug 吗？

**不是 bug，这是效果本身。** 因为绿、蓝通道被模糊了而红色没有，边缘就出现了红蓝分离的镶边。这正是「屏幕变远」的视觉线索。

镶边越明显 = 离焦模拟越强 = 效果强度越高。如果你觉得太夸张，往下调「效果强度」就行。

### Q5：为什么我的字看起来有点发糊？

大概率是效果强度偏高了，或者观看距离填得比真实值小。回看第 5.4 节的两张对照表。

另外注意：**强度调高 + 长时间用**，确实可能让眼睛更累。觉得不舒服就调低或暂停。

### Q6：我有两块屏，能分别设置吗？

可以。打开设置面板 → 选「单独改这块屏」→ 在显示器列表里选中目标屏幕 → 调它的参数。两块屏互不影响。

### Q7：为什么游戏里没效果？

如果游戏是**「独占全屏」**模式，系统抓屏接口拿不到画面，这是硬件/系统层面的限制，不是软件的问题。

程序会**自动暂停**并在托盘提示你。把游戏设置成「**无边框窗口**」或「**窗口化**」就能生效。

### Q8：需要管理员权限吗？

**不需要。** 普通用户权限即可运行。

### Q9：程序会不会联网、收集我的信息？

**完全不会。** 本程序不包含任何网络代码，不联网、不上传、不收集任何数据。你可以用杀毒软件扫描确认。

### Q10：我的屏幕是 HDR / 10bit 的，能用吗？

能用，但**请先把系统的 HDR 关掉**。

本软件**不做 HDR 适配**——开着 HDR 时画面会明显偏色/过曝。如果你看到偏色，先去系统显示设置里关掉 HDR。

至于 10bit：程序会**跟随抓屏源给的格式**，源只给 8bit 就自动降级到 8bit，属正常现象。

### Q11：怎么完全卸载？

1. 右键托盘图标 → **退出程序**；
2. 打开托盘右键菜单里的「开机自启」把它关掉（如果开着）；
3. 删掉 exe 文件；
4. 删掉 `%APPDATA%\MyopicDefocus\` 整个文件夹。

> **「暂停效果」是真暂停**：滤镜窗口会被隐藏，画面立刻恢复原样，而不是冻结在最后一帧。

## 十一、哪些地方不会被离焦（技术边界）

滤镜是覆盖全屏的合成层，因此以下由系统直接绘制的顶层窗口会**保持清晰、不带离焦效果**：

- 按 Win 键打开的开始菜单、搜索框
- 输入法候选框（如 Rime）
- 右键菜单、通知中心、部分安全软件界面

这是全屏合成方案的固有边界：这些窗口由 shell 以更高的层级绘制，无法被普通应用覆盖。反过来强行把滤镜提到最前，输入法候选框反而会被遮住、无法选词。

这些弹出层通常出现时间短、面积小，日常阅读长文本时基本无感。若你确实需要它们也被处理，只有改用「逐窗口合成」路线，复杂度与兼容风险都高得多。

### 如果右下角没有图标

先确认 exe 是不是还在开发工作区目录里（`01_PROJECTS`、`07_EXPORTS` 这类路径）。这些目录被 Windows 打了「低完整性级别」标记，会导致托盘图标建不出来。

**把它复制到桌面再运行即可。** 详细说明见《故障排除》第 2.18 节。

### 全屏游戏时自动暂停

设置面板「其他设置」区里有一项 **「检测到全屏游戏时自动暂停效果」**（默认开启）。

**它怎么判断「游戏」**：靠 DXGI 抓屏连续失败。独占全屏的游戏会接管显示输出，此时 Desktop Duplication 拿不到画面，程序据此判定「进入了独占全屏」。

**为什么普通全屏窗口不会误伤**：普通窗口全屏时输出并没有被接管，抓屏照常成功，所以不会触发。判断依据是「输出被独占」而非「窗口铺满屏幕」。

**行为**：
- 检测到 → 立即暂停离焦效果（滤镜层隐藏，画面恢复正常，不会卡成冻结的最后一帧），托盘弹一条提示
- 游戏退出或切回桌面 → 自动恢复，并再弹一条提示
- 关闭该选项 → 不再自动暂停；遇到抓不到画面时只提示「可能正在运行全屏独占游戏，请改为无边框窗口」

### 屏幕对角线不用填了

早期版本要求你手动填屏幕对角线。现在程序会**自动从显示器固件（EDID）读取物理尺寸**——这是显示器出厂时写死在硬件里的数据，比人拿尺量准。

自动探测失败时（极少数虚拟显示器 / 信息缺失），程序使用默认值 24 英寸。对效果的影响：对角线参数只影响模糊半径的换算，差 1~2 英寸视觉差异很小，无需担心。
